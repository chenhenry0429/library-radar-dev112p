## 1. 结论

v1.2 背景快照方案在 P01 上修复了 v1.1 的两个耦合病理：

| 指标 | v1.1（ema α=0.02，m1_result/） | v1.2（snapshot_freeze，m1_result_v12/） |
|---|---|---|
| 空座段误报 | **81/102 帧（79%），4.06 s 起持续 FP** | **0/102 帧** |
| 入座确认 | 无意义（状态由空座 FP 延续） | 物理入座边界（19.737 s）后 **+4.45 s**（24.19 s 翻转；23.2 s 起持续过阈） |
| 占用段保持 | 无法评价 | **715/715 = 100%**（确认后零误释放、零漏检） |
| 静坐检出延迟（v1.1 α=0.2 变体） | 72 s（EMA 吸收） | n/a（快照不吸收） |
| 结束状态 | 1 | 1（EOF 仍占用，正确） |

A 端程序 1.0.1 独立复验参考：初始空闲确认 3.096 s、入座确认 21.8655 s（事件语义，含其内部防抖）。v1.2 的 24.19 s = 边界 + 4.45 s，其中 confirm=6 帧（1.16 s）+ 入座过渡期（前 ~1.3 s 残差仍处空座水平）+ score 爬升；量级与 A 端参考一致。

## 2. 问题（v1.1 在 P01 上暴露的病理）

v1.1 背景为「无人帧 EMA 更新、有人帧冻结」，在真实设备上存在确认-吸收竞速：

- **α=0.2**：EMA 时间常数 ~1 s，6 帧确认窗内吸收入座者 −11.7 dB → 静坐者 **72 s** 才触发（吸收病理）。
- **α=0.02**：确认窗内仅损失 ~1 dB，可正常确认入座；但空座段漂移（+8.8 dB/162 s）追不上 EMA → 空座残差持续高于判决门限 → **4.06 s 起全程 FP（81/102 帧）**。
- 两参数无法同时满足「不吸收入座者」与「跟上空座漂移」——结构性矛盾，须换背景模型。

## 3. 修复设计（v1.2 snapshot_freeze）

背景状态机（`algos/m1_features.py`，`background.mode="snapshot_freeze"`）：

1. **初始累积**：录制开场（空座，协议要求）对前 `snapshot_frames=50` 帧（9.7 s）累积运行均值；
2. **占用冻结**：首帧 presence=1 或累积满 50 帧即冻结（不满时用 K_eff 部分窗口），占用全程背景完全静止 → 不吸收静坐者；
3. **证据级释放重建**：确认释放后，累计 `re_snapshot_confirm=90` 个「证据级空帧」（score ≤ t_off）→ 重建快照（漂移/环境变化自适应）；
4. **两处护栏**（本次迭代加固）：
   - hysteresis 波峰帧（t_off < score < t_on）**既不计数也不重置**空帧计数器 → 入座未确认段、空座瞬态波峰（0.33 Hz 环境扰动，2–4 帧波峰）不可能误触发重建；
   - 累积期（初始或重建）**只吸收 score ≤ t_off 的帧** → 重建期间快速回座者的未确认帧不入快照；确认时以任意 K_eff 冻结（K_eff=0 保留旧快照）。

配套特征改动：`f1_bins="non_main"`（F1 排除 main_bin 2——该设备环境扰动集中于主 bin，占用者反射在 bin 1/3）；`f1_db_map=[30, 43.5]`（见 §4）。

## 4. 校准方法学（为何 map 必须开环标定）

map 经 score→presence→背景策略反馈进状态机：宽 map 会使空座帧 score>t_on → FP → K_eff=7 部分冻结 → 吸收循环 → 污染分布测量。**校准必须开环**（F1 对固定 K=50 冻结快照，无状态机）：

开环分布（P01，F1=非主 bin 残差功率 dB）：

| 段 | P50 | P99/P10 | 备注 |
|---|---|---|---|
| 空座（0–101 帧） | 28.76 | P99 = 36.01 | max = 36.71 |
| 入座过渡（102–133） | 34.61 | max = 40.63 | 弱点：前 ~1.3 s 与空座分布重叠 |
| 稳定占用（134–839） | 45.19（P05 = 37.06 / P10 = 38.76） | — | 姿势「谷」588–661 帧绝对功率 P50 = 47.5，无真实谷 |

选 map [30, 43.5]：span=13.5，score 判决交叉点 = 30 + 0.5625×13.5 = **37.59 dB** —— 高于空座 P99（36.01）1.58 dB（误报裕量），低于稳定占用 P10（38.76）1.17 dB（检出裕量）；释放交叉 = 35.06 dB（离座后残差 28–33 可正常释放）。闭环验证：空座 FP 0/102、确认 24.19 s、全程保持、无 1→0、快照 #1 K_eff=50 后无重建。

## 5. 回归验证

### 5.1 G1 合成 20 条：v1.1 行为不变性

代码改动（snapshot 分支 + f1_bins + 版本标签覆盖）对 EMA 路径零扰动：默认配置重放 20 条（1d/2d），presence/target_count/timestamp/quality 四列与入库基线 **20/20 逐字节一致**。

### 5.2 S06 lifecycle 合成场景：离座释放回座（P01 无离座，此为释放/重建路径当前唯一实测）

`tools/make_synthetic_g1.py --lifecycle` 新增场景（不进 G1 20 条基线）：enter@10 s → leave@28 s → re-enter@46 s，1 Hz，真值区间 [10,28)/[46,60)。测试配置 `config/M1_lifecycle_test_v12.json`（snapshot_frames=8 适配 10 s 空场前缀、re_snapshot_confirm=12）。

结果（两条 1d 段一致）：presence 区间 **[14,31]、[50,59]**——

- 入座确认延迟 4 s、离座释放滞后 3 s、回座确认延迟 4 s（全部 = confirm=5 帧防抖，设计内）；
- FP 帧 4 个 / FN 帧 8 个，全部为上述防抖帧，无真实误报/漏检；
- **快照状态机轨迹**：`#1 frozen (K_eff=8)`（开场空座）→ 释放后 `rebuild triggered (12 empty-evidence frames)` → 重建累积 2 个干净空帧（44、45）后回座者入场：回座帧 score 0.60 > t_off **被护栏跳过、未入快照** → 再确认时 `#2 frozen (K_eff=2)`——部分快照只含空座帧，回座者未被吸收，检测不受影响。

该场景同时验证了 v1.1 病理的反面：若重建吸收回座者（v1.1 语义），[46,60) 段将永不检出。

## 6. 已知限制

1. **开场空座前提**：录制必须以空座开场（≥ snapshot_frames=50 帧 ≈ 9.7 s）。P01 满足（19.7 s）；P02/P04 待检查。若开场即有人，初始快照将吸收该人（结构性限制：无空座参照）。开场后入座太快（<9.7 s）亦会部分吸收——score ≤ t_off 护栏可减轻但帧 0 无参照。
2. **长空位漂移**：占用释放后，若空位段超过漂移判据耐受（实测漂移 +8.8 dB/162 s ≈ 0.054 dB/s，距释放交叉有 ~117 s 裕量），90 帧（17.4 s）证据级重建在裕量内可完成漂移再校准；超长录制尾部仍可能释放失效——P02/P04 长录制重点观察项。
3. **静态门失效（沿袭 v1.1）**：环境 0.33 Hz 扰动占据呼吸带 → 空座 f23 恒高 → f23_floor 静态门不动作。门项在空座波峰贡献 ≤ 0.12·gate，由 confirm=6 过滤。
4. **入座确认延迟 ~4.5 s**：入座过渡期（前 ~1.3 s）残差处于空座分布内，属物理极限；如需更快确认需缩短 confirm（与抗扰妥协）。
5. **释放路径未在真实数据实测**：P01 无离座；当前证据 = S06 合成验证 + 判据计算（释放交叉 35.06 dB vs 离座后残差 28–33 dB）。待 P02/P04。
