## 1. DEV112P 硬件身份（原理图 + UM10059P 2.16 / 表 1-1）

架构：**2 颗 ICL1122（1T2R SoC）Master/Slave 级联 + 1 颗 MCU**，实现 2T4R MIMO。

| 参数 | 值 | 来源 |
|---|---|---|
| 传感器 SoC | **2 × ICL1122**（S5 系列，24 GHz 1T2R，QFN32）级联 = **2T4R** | 原理图 Page01/02；UM 2.16.1 |
| 主控 MCU | **AT32F403ACCT7**（雅特力 Cortex-M4，240 MHz，SRAM 96+128 KB）——即参数表"M4 MCU 高性能"，此前疑点已解 | 原理图 Page03；UM 表 1-1 |
| SoC↔MCU 互联 | 参数配置走 **I2C**；数据传输走 **SPI**（Master：SPI1/SPI2；Slave：SPI3/SPI4；双 MOSI） | 原理图；UM 2.16.1 |
| 芯片间级联 | LO_BUF、SYNC_OUT→SYNC_IN、RAW_CLK 互连（两颗共用本振/时钟） | 原理图 Page01/02 |
| 对外接口 | **J1：UART RX/TX + GND + 5V**；J2 烧录口（DIO/CLK/3V3） | UM 表 2-16-1/2 |
| 供电/功耗 | 5 V 供电，峰值电流 202 mA，TTL 3.3 V | UM 表 1-1 |
| 波束宽度（6 dB） | E：±50°，H：±40°；天线增益 6.5 dBi | UM 表 1-1 |
| 天线布局 | TX1–TX2 垂直/水平间距 5.9 mm；RX1–RX2、RX1–RX4 纵向 5.9 mm；RX3–RX4 水平 5.9 mm | UM 2.16.2 |
| 尺寸 | 44 × 23 mm | UM 表 1-1 |

通道归属与测角（UM 2.16.2）：

- 主芯片（`cfg_msg` 值 0）：TX1、RX1、RX2；从芯片（`cfg_msg` 值 1）：TX2、RX3、RX4
- 透传接口 `channel` 0~3 = chip0 RX0、chip0 RX1、chip1 RX0、chip1 RX1
- **H 面测角**：TX2-RX1、TX1-RX4（补偿 −93°）、TX1-RX3（补偿 −88°）；**E 面测角**：TX1-RX1（+10°）、TX1-RX4（−55°）、TX2-RX3（−16°）——M1 区域限定可直接引用

**与 DEV113P（计划书原文）的关键差异**：

| 项 | DEV113P（计划书） | DEV112P（实际购买） |
|---|---|---|
| SoC | ICL1240 单芯片 2T4R，内置 RISC-V MCU 200 MHz | 2×ICL1122 级联 2T4R + 外置 AT32F403A M4 @240 MHz |
| ADC | 50 MHz / 12 bit | **2.5 MHz / 16 bit** |
| 点云 | 官方口径"点云感知能力" | **无直接点云输出**（见 §3.2） |

## 2. 官方数据通路（两级交付，UM 第 1 章 + 2.16.3）

矽典微为各套件提供两种官方工具：**毫米波传感器开发工具**（上位机，实时呈现、快速评估）与**数据透传固件**（板载，多种接口）。

### 2.1 透传固件路径（C 的主数据通路）

```
ICL1122 ×2（级联 2T4R MIMO）
   │  ADC 2.5 MHz/16 bit；片内 DSP（超分辨率/滤波/CFAR 目标检测）
   │  SPI（Master: SPI1/2，Slave: SPI3/4；双 MOSI；单路瞬时 < 25 Mb/s）
   ▼
AT32F403A（M4 @240 MHz）—— 数据透传固件
   │  App 层分发接口：
   │    · AlgorithmProcessFun：开发验证自己的固件算法
   │    · StartDataTransfer：透传数据给上位机
   │  分发参数：frameBuf（含头尾）、bufLen、channel（0~3）、index（Chirp 序号）
   │  MCU 封包：Head"ICLH"(4B) + Length(2B LE) + Type(1B) + Extra(1B) + Data + Tail"ICLT"(4B)
   │    · Type=0x00 芯片数据（Extra=通道/SPI 号；Data 格式见 DS10012RN_ICL1122）
   │    · Type=0x80 温度（Extra=芯片序号；Data=4B Code 值）
   ▼
UART 921600 bps → USB 转 TTL → 上位机
```

**可透传数据类型（UM 2.16.3 原文）**：

- `dsraw`（DS RAW 原始数据）——按 **chirp** 传输，含"输出降采样间隔"参数
- `1dfft`（Range FFT 距离谱）——按 **chirp** 传输
- `2dfft`（Doppler FFT，距离-多普勒谱）——按 **frame** 传输

**传输速率限制（UART 921600 bps，UM 原文公式）**：

- RAW / 1dfft：chirp 总时间 (µs) > (点数×4+8)×(8+1+1)×Rx_Num / 921600×10⁶ / 降采样间隔 × 1.15
- 2dfft：Frame 周期 (ms) > (DPL 行×DPL 列×4+8)×(8+1+1)×Rx_Num / 921600×1000 + 5
- 另：chirp 时间 > SPI 单次传输时间；SPI 单路瞬时 < 25 Mb/s

**配套机制**：波形参数经开发工具生成寄存器配置（如 `40=4207`）→ 复制到固件 `Config\radarPara\DEV112P\regs.txt`；内存按 `RADAR_DATA_MAX_LEN` 宏（点数×4 字节）调整。

### 2.2 开发工具路径（评估用）

上位机"毫米波传感器开发工具"可实时呈现数据（用法见工具"帮助"菜单）；其**数据导出能力（层级/格式）需 B 实测**。

## 3. 静态目标去除环节分析（任务一①核心）

### 3.1 v0.2 更新判断

**透传固件输出的是 dsraw / 1dfft / 2dfft——即片上 DSP"目标检测"之前的原始级与中间级数据**。ICL1122 片内 DSP 的"超分辨率/滤波/CFAR 目标检测"位于透传数据之外的芯片内部目标检测路径上。

含义：

- **M1 采用透传数据（1dfft 或 dsraw）时，背景去除与静态目标处理的控制权完全在 C 手中**——M1 的"背景估计与冻结"设计不再受固件 MTI 行为制约【重大利好】；
- 仍需 DS10012RN 确认：**1dfft 是否复数（含相位）**——F2 相位方差、F3 呼吸频段的必要条件；以及 FFT 前后有无去直流/去静态等片内预处理。

### 3.2 候选环节清单（v0.2）

| # | 环节 | 状态（v0.2） |
|---|---|---|
| C1 | 芯片内部目标检测路径的静态滤除 | 与透传路径**无关**（透传绕过它）；仅当使用芯片目标列表输出时才相关 |
| C2 | dsraw/1dfft 数据本身的预处理 | dsraw 含"输出降采样间隔"（抽样）；FFT 前有无杂波预处理【待 DS10012RN】 |
| C3 | 1dfft 复数性（相位可得性） | 【待 DS10012RN】——F2/F3 成败关键 |
| C4 | B0 的"官方点云"来源 | DEV112P **无直接点云输出**。候选：① 开发工具导出（B 实测）；② 芯片目标列表（DS10012RN 是否含）；③ C 自 2dfft+CFAR 重建。**B0 基线定义需小组决策**，若走③需知会教师（"官方基线"弱化为"标准方法基线"） |

### 3.3 G1 旁证（不变）

矽典微 XenD/P 系列成品（S1/S3/S5 系芯片）明确支持静坐/静卧检测；ICL1122 同属 S5 体系——静坐检测在矽典微技术体系内是成熟能力。

## 4. 对 B0 / M1 的直接影响（v0.2）

- **M1**：数据通道打通——1dfft 距离谱按 chirp、逐通道（channel 0~3）透传可得，F1/F2/F3 有数据基础【复数性待 DS10012RN】；dsraw 为兜底（自算 FFT，控制最彻底，但 UART 带宽压力大）。
- **B0**：风险从"静态目标可见性"转移为"点云来源"（§3.2 C4）。
- **带宽与帧率**：921600 bps 下须按 §2.1 公式核算点数×通道×帧率组合；呼吸频段（0.1–0.5 Hz）所需 ≥5 Hz 帧率量级下通常可满足，但 4 通道全开时需具体核算。
- **距离分辨率待确认**：UM 电气性能测试带宽 24~24.25 GHz（250 MHz）→ 若单 chirp 实际带宽同量级，距离分辨率 ≈ c/2B ≈ 0.6 m——**座位区域限定将主要依赖角度维（§1 测角通道），距离维仅粗分**。B 配置时确认最大可配置带宽。
- **开发自主性**：固件 App 层提供 `AlgorithmProcessFun` 接口——如需片上实时算法（阶段三+），有官方扩展点。

## 5. 建议行动（v0.2 优先级）

1. **向厂商索要 `DS10012RN_ICL1122` 数据协议文档**（UM 明确引用）——一次解决 C2/C3/C4（数据格式、复数性、cfg_msg、有无目标列表）【第一优先】；
2. **B 实测开发工具的数据导出**（点云/距离谱/RD 图的层级与格式）——直接决定 B0 候选①是否成立；
3. **B 按传输公式核算帧率-点数-通道组合**，并确认最大可配置带宽与距离分辨率，产出 G1 采集配置；
4. **小组决策 B0 基线定义**（若①②均不可得，走③自建点云并知会教师）；
5. **同步修订项目计划书硬件型号（DEV113P→DEV112P）**，对教师/对外材料一并更正。
