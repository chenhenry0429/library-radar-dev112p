# D · 独立标注与评价

**当前状态**：已约定独立文件接口，尚无评价程序或实测指标。selftest 是软件边界测试，不能替代识别准确率评价。

输入：独立观察标注、B 的记录说明，以及 C/A 已冻结的输出；评价用标签不能传回 C 推理或 A 状态处理。

建议 labels.csv 表头：start_timestamp,end_timestamp,seat_id,presence_label,posture_label,event_label,annotator。区间左闭右开 [start,end)，过渡、经过、挪椅、离座返回应单独标注。

下一项任务：制定标注细则、匿名人员编号和独立 split.json，同一人不跨训练/验证/测试；先实现逐帧存在及姿态的有效区间对齐，再评价业务事件时间。

交付：评价脚本、按 source_kind 分开的指标汇总、错误分析和可复现参数；真实标签与个人信息保存在本地/获准的数据存储，不提交本公开仓库。

验收：不混用 synthetic 与 measured 指标，不将算法自身输出作为真值；明确未知/拒识的计分方式、样本数量和人员划分；记录漏检、误报及提醒/释放延迟。
