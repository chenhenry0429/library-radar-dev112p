## 下一步与交付

1. **标注细则**：明确空场、静坐、过渡、经过、挪椅、离座返回及参考/前倾/后靠的定义。
2. **标签文件**：制作模板并校验时间区间，保证与采集相对秒一致。
3. **人员划分**：独立维护匿名人员编号和 split.json，同一人不跨训练/验证/测试。
4. **评价程序**：对齐有效区间，再评估漏检、误报、未知/拒识和事件时间误差。
5. **结果报告**：分别报告 synthetic / measured，写清样本数量、人员划分和参数。

labels.csv 建议表头：

```text
start_timestamp,end_timestamp,seat_id,presence_label,posture_label,event_label,annotator
```

区间左闭右开 `[start,end)`；算法结果不能作为真值，测试标签不能传入 C 推理、C 参考段选择或 A 的运行状态处理。A 和 D 虽由同一成员负责，也保持这一边界。

真实标注与个人信息保存到获准的数据存储，不提交公开仓库。本目录后续存放标注规范和评价代码。
