## 数据包说明

raw.npz 中的 raw_data 是设备输出的距离 FFT（1DFFT）数据，形状为 (497, 2, 2, 64, 8, 2)，数据类型为 int16。轴编号从 0 开始。

| 轴 | 含义 | 单位 |
| --- | --- | --- |
| frame | 按数据流顺序记录的 497 个帧组 | 帧组序号 |
| chip | 两颗雷达芯片 | 芯片索引 0、1 |
| rx | 每颗芯片的两个接收通道 | 接收通道索引 0、1 |
| chirp | 每帧、每通道的 64 个线性调频脉冲 | chirp 索引 |
| range_fft_bin | 设备输出的 8 个距离 FFT 分箱 | 分箱索引，米制距离映射待标定 |
| iq_component | 0 为实部 I，1 为虚部 Q | 设备 FFT 计数值，无物理量单位 |

设备配置开启发射轮询。归档保留原 chirp 序号，物理发射天线映射待核实。I/Q 是设备输出的定点 FFT 数值。

valid_chirps 标记每个帧组、芯片、接收通道、chirp 是否收到完整数据包。缺包处填 0，以布尔掩码区分缺包和真实零值。497 个帧组中有 495 个完整帧组，全部 127,160 个校验通过的 FFT 数据包均已保留。

frame_ids 为从 0 开始的帧组序号。device_frame_ids 保留设备循环计数（模 16）。nominal_time_s 按配置帧周期 0.1935 秒从首个帧组推算，单位为秒。现有 v1 交接接口要求逐帧实测时间，本归档使用独立格式，供离线回放。

~~~python
import numpy as np

with np.load("raw.npz", allow_pickle=False) as z:
    complete = z["valid_chirps"].all(axis=(1, 2, 3))
    iq = z["raw_data"][complete]
    nominal_seconds = z["nominal_time_s"][complete]
    complex_fft = iq[..., 0].astype(np.float32) + 1j * iq[..., 1]
~~~
