# 独立标注与评价 v0.1.0

A 与 D 均由 stone140 负责；D 的标签和评价只在独立工具中使用，不输入 C 推理、参考选择或 A 状态机。

## 标签规则

固定七列 start_timestamp,end_timestamp,seat_id,presence_label,posture_label,event_label,annotator；区间为 [start,end)。同一文件一个座位，按时间递增、无重叠，unknown 区间不计入分类准确率。未覆盖区间与显式未知分开统计。

presence_label=0 为目标座确认无人，1 为确认有人，unknown 为证据不足。空座 posture_label=not_applicable；本轮所有有人/过渡 posture_label=unknown。前倾、后靠的到位口令不能自动提供整个片段的姿态真值。

标注依据只用现场记录或独立视频；禁止将 C 的结果、波形变化点或预测边界抄作真值。P01、P03 没有独立动作时刻，不生成动作真值。

## 现场记录整理与时钟

prepare_annotations.py 输入 B 端 meta.json 与采集记录.md，只生成本地标注包。P02、P04 等先从动作到位后 2 秒至下个动作记录前 5 秒整理核心区间，尾部留 2 秒；短于该留白的区间保持未知。首个坐稳前不假定空座。椅子移动期间不假定无人。每条来源文件哈希保存在 annotation.json。

这些留白仅为初步分析策略，不证明动作已经持续、同步误差小于留白或标签已人工复核。记录为 field_log_derived_pending_review，需保留现场记录供复核。

秒表坐稳/离座时刻与雷达首帧存在未测偏移，标签保留 stopwatch 时钟；不得擅自认作 recording_start。邻座/过道现场明确确认目标座全程空，可按完整内部帧区间构造常量空座标签，首尾不完整帧不纳入。

评价默认拒绝未复核标注；如仅做调试，需要同时 --allow-provisional 和明确 --offset-s。方向为 prediction_time = label_time + offset_s；0 是显式假设，不是默认已对齐。报告标为 provisional_not_acceptance。正式评价先确认并记录 reviewed 状态、偏移和误差依据；名义时间不用于真实响应时延验收。

## 指标与范围

evaluate_presence.py 输出帧级 TN/FP/FN/TP、真实空座/有座上的预测未知、有效分类覆盖率、已分类准确率、误报/漏报和拒识比例。有效真值中的预测未知保留在总分母，不通过删除未知美化指标。无对应类别时比例为 null。

时间统计只在相邻有效时间间隔不超过显式 max_gap_s 时累计，按标签边界精确切分；缺口不保持上一状态，末帧之后不补时间。事件延迟不自动计算：核心区间不是动作起点，缺少已验证对齐。未从程序获得实际预测文件的录制不输出准确率。

评价程序不改 C 的分数和阈值；不把姿态未知推断为异常。结果中保存算法与参数版本、所有输入哈希、时间基准和排除量。

## 划分与交接

既有 P01–P04 数据已暴露给开发过程，统一列为 development，validation/test 为空，不能追认为独立测试集。开发期间同一批标签可用于比较版本，最终需冻结后另取独立数据/参与者。

main 只提交规范、代码、合成测试和不含个人记录的汇总；真实 labels/annotation 保存在本地或获准数据存储。本轮交接给 C 的是受控独立评价，不把标签作为算法推理输入。
