# DEV112P 自习位占用与坐姿提醒 · 技术细节总结

> 作者：C（cy071210）｜更新：2026-11-24｜对应分支 `feat/c-v1.2.1`（PR #9）
> 定位：把「硬件 → 数据 → 算法 → 在线链路 → 业务状态 → 评价」的完整技术链路写成一份
> 可复查的参考，数字均来自仓库内实测产物（`outputs/`、`examples/`）。

## 0. 一句话

在图书馆六人桌的每个座位上，用毫米波雷达对**座位区域的距离像**做逐帧分析：先把
原始数据规整成「每帧 8 个距离 bin 的复数剖面」，再用**开场空座标定 + Bin1 微动 +
背景差异稳定性**判断有人/无人，输出逐帧证据给应用层；再对通过质量门的数据做
**个人参考下的粗姿态（前倾/后靠）识别**，最终由应用层决定「占用 / 离座等待 60 s /
释放 / 提醒」。本项目 4 周内交付单座闭环与在线逐帧入口，多座位扩展仅保留接口。

## 2. 硬件与数据规格

- 设备：DEV112P（两颗 ICL1122 的 2T4R 开发套件，MCU 透传 1DFFT/2DFFT 结果）。
  频段/带宽/空间分辨能力以厂家手册与实测为准，仓库不猜测未知电气参数。
- 一帧 = 2 chip × 2 rx × **64 chirp** × **8 距离 FFT bin** × (I,Q)，int16 计数。
- 帧率 **5.168 Hz**（名义周期 **0.1935 s**），时间轴 = `frame_id × 0.1935 s`
  （nominal，秒表-雷达偏移未实测）。
- `valid_chirps[frame, chip, rx, chirp]` 标记包是否收全；首/尾帧常为部分帧
  （如 212/256、196/256），缺包处填 0，用掩码区分「缺包」与「真实 0」。
- **tx_polling=1**：奇/偶 chirp 走不同发射通道，同一目标幅度差 ~11×
  （T01 实测奇 ≈16200 / 偶 ≈1450 counts）。
- 距离 bin 未标定到米；区域 `[1,3]`、主 bin `2` 是信号标定（呼吸证据）而非几何测距。

## 3. 数据链路（四段）

```
ONELAB/雷达 ──B 归档──▶ raw.npz+meta ──C 投影──▶ [帧,2,8] 复数
   ▲                                              │
   │                                              ▼
   └── A 页面/状态机 ◀──HTTP 逐帧 9 列证据── C 状态机（M1 v1.2.1）
                                                  │
                                        D 独立标注/评价（离线）
```

1. **B 归档**：原始 `.dat`（ONELAB 流，`ICLH+len+type+extra+data+ICLT` 封包）→
   解码为 `raw_data/valid_chirps/frame_ids/nominal_time_s`，归档带 SHA-256、
   完整性统计（valid_packets/partial_frames）；真实标签不入 main（data 分支）。
2. **C 投影**：选 chip1/rx0（呼吸证据最强、无饱和）；**奇/偶 chirp 分开复均值**
   → `[frame, chirp_parity, range]`；输出规范 meta（axis_order/data_level/安装）。
3. **C 算法**：M1 v1.2.1（见 §4），逐帧 9 列行。
4. **A 业务**：presence 连续 2 s → `in_use`；连续 3 s 空 → `leave_wait`（60 s
   倒计时）；倒计时中再连续 2 s 有人 → 取消并回 `in_use`；60 s 到 → `released`。
   `data_gap_s=2.0` 断流保护、`review_after_s=30` 复核、置信度 <0.6 视为 unknown。
5. **D 评价**：独立标签、按人划分，报告误报/漏报/延迟；秒表偏移未测前只作
   provisional。

## 4. C 算法：M1 v1.2.1

### 4.1 输入与区域

- 输入：`[帧, 2(奇偶), 8(bin)]` 复数 + 时间戳（或 v1.2 的单链 `[帧, 8]`）。
- 区域：`region=[1,3]`，`main_bin=2`（环境扰动/呼吸），**微动判据用 Bin1**
  （目标座反射体，幅度 3500–10000 counts）。
- 退化路径：实数输入 / 无区域信息时降级并如实记 warnings。

### 4.2 预处理（两件关键事）

1. **奇偶分链**：避免 11× 幅度差被平均、避免 frame0 奇偶配比（27/26）造成
   +139 counts 的种子偏置——v1.2 开场锁死背景的直接原因。
2. **泄漏归一**：每个 bin 除以 bin0 得幅度比 `q=|X_b|/|X_0|`。bin0 是设备泄漏
   （与场景无关），归一后消除热状态/场次基数差（实测 3538–10245，2.9×）。

### 4.3 每帧特征

| 特征 | 公式/窗口 | 用途 |
|---|---|---|
| F1 背景差异 | `10·log10(Σ_{b∈{1,3}}\|q_b−q̄_b\|² / Σ\|q̄_b\|²)`，`q̄` 为标定空座均值 | 背景变化证据；判空时要求 **稳定**（\|Δf1\|≤6 dB） |
| Bin1 微动 m | 10 s 窗内 `\|X_bin1\|` 去线性趋势的 std ÷ 均值，再 ÷ 标定噪声底（P20） | **主判据**：静坐是空座的 1.4–8.7×（20 cm 组 6.7×） |
| 快窗 m4 | 同上，4 s 窗 | 判空辅助（≤2.2） |
| F2 相位 std | 主 bin 4 s 展开相位 std ÷ 0.03 | 诊断（不参与判决） |
| F3 呼吸带 | 主 bin 0.1–0.5 Hz 能量占比（排除 DC） | 诊断（环境 0.33 Hz 干扰会打满） |
| quality | 区域平均功率 < −60 dB → `low_signal`；NaN → `invalid_frame` | 输出 presence=-1，不冒充 0/1 |

**为什么用微动不用幅度**：静坐者让 Bin1 均值只变 −0.3%~−2.4%，与 90 s 内 −9 dB
漂移同量级；而微动/方差差 2–8×。判据放在「动」上，均值只做辅助。

### 4.4 开场标定（10 s + 整窗等待）

- 前 **10 s 且 ≥40 有效帧**只累积：背景 `q̄`、噪声底（m 的 P20）、F1 参考；
  标定期 **presence 恒 0**（不判）。
- 标定结束后**再等满一个 10 s 微动窗**（≈20 s）才启用判决：避开摆位/上电过渡段
  （484 帧现场 11.61 s 误报即由此产生，修复后 0 帧误报直到 27.5 s）。
- 噪声底只在**无人态**慢更新（α=0.02），且不低于标定值的 **0.8 倍**（防安静段
  把底拉低→灵敏度跳变）。

### 4.5 判决状态机（双阈值，快进慢出）

```
入场：m ≥ 4.0 且连续 8 帧（≈1.5 s）        → presence = 1
保持：不满足判空条件                        → 保持 1
判空：m ≤ 1.45 且 m4 ≤ 2.2 连续 26 帧（≈5 s）
      且 |Δf1|（2–10 s）≤ 6 dB              → presence = 0
      → 用最近 10 s 重建空座快照（背景 + 噪声底 + F1 参考）
```

- 入场用「明显动」，判空用「持续静」；占用期冻结基线（防静坐者被吸收入背景）。
- 判空后重建快照，使下一次入场以新的空座水平为基准（适应漂移）。
- 输出 `score=clip((m−1.45)/2.55)`、`conf=0.5+0.49|2·score−1|`（离边界越远越高；
  灰区 conf<0.6 会被 A 当 unknown）。

### 4.6 输出契约（9 列）

`frame_id, timestamp(repr float 往返), presence(1/0/-1), presence_confidence,
target_count, posture, posture_confidence, calibration_status, quality`

- presence=-1 只在 quality≠ok（≠空/有人），A 侧转为 unknown；
- 写盘后立即跑 selfcheck（C1–C8：行数、帧号连续、时间戳严格递增/往返、值域、
  posture 词表），FAIL 非零退出。

## 5. 在线链路（v0.1）

- `SeatDetector`：一次会话一个实例，frame_id 0 起连续、timestamp 严格递增；
  `feed_frame`（已投影剖面）/`feed_dev112p`（B 单帧立方，C 侧投影）。
- **同一状态机**：离线 `run_m1` 与在线 `SeatDetector._m1_step` 共用
  `M1V121State.step` → 同数据 result.csv/scores.csv **逐字节一致**（已验）。
- HTTP：串行 POST `/api/frame`（九字段 JSON），Bearer token；HTTP 4xx 不重试立即
  中止，网络错误指数退避 + `GET /api/state` 对齐防重复帧；capabilities 只放
  `{presence, posture}` 纯 bool；A `--live` 启动读 `_algorithm_online.json`。
- 零有效 chirp 帧 → 输出 `invalid_frame` 行（presence=-1），不推进状态机。

## 6. 姿态 M2 v0.1（gated baseline）

- 参考标定：presence=1 稳定 10 s 后取 50 帧统计能量重心/能量和；
- 特征：region±2 bins（排 bin0）的能量重心与能量和；
- 质量门：参考窗 vs 紧随窗重心差 <2.0×合并 std → **拒识**（posture=unknown,
  calibration_status=invalid）；
- 分类（过门才启用）：Δcentroid ≥ ±0.02 bin → forward/backward；能量比越界
  [0.5,2.5] → unknown。
- 实测：11/12 组被对比度门如实拒识（当前数据不可分），P01 过门但方向不可验证。
  **能力声明为「管线已实现」，不是「能识别姿态」**。

## 7. 数据集与评价口径

- 12 段 T01 真实录制（2026-11-12 11 段 + 11-17 椅移 1 段），
  6 正式 + 2 复测 + 1 椅移 + 3 试录；另有 484 帧（11-19，20 cm）与 1,031 帧
  （11-23，20 cm）现场抓包。
- 真值：现场秒表事件（坐稳/走远/返回），`provisional`（秒表-雷达偏移未测）。
- 指标口径：开场误报 = [标定结束, 首次坐稳) 内 presence=1 帧数；静坐保持 =
  入场后有人区间命中率；走远判空 = 离座事件到 presence=0 的延迟；
  全空组 = 邻座/过道（目标座全程空）的误报帧。

## 8. 关键结果

| 指标 | M1 v1.2 | M1 v1.2.1 |
|---|---|---|
| 开场空座误报（9 组真实） | 240/240 (100%) | **0/240 (0%)** |
| 开场（含 484 抓包） | 341/341 (100%) | 11/341 (3%，均为坐稳前 2 s 到座) |
| 邻座/过道全空组 | 532/532 (100%) | **0/532 (0%)** |
| 走远判空 | 0/8 次释放 | **4/8 次（9.0–10.1 s）** |
| 静坐保持（入场后） | 100%（靠永不释放） | **99%**（唯一损失：12 s 完全静止） |
| 484 现场 | 1.5 s 翻 1、零释放 | 27.48 s 入、67.53 s 出（走远后 9.47 s） |
| 在线/离线 | — | result/scores 逐字节一致 |

v1.2 的缺陷量化（round-2 报告）：11/12 组空座误报 93.8–98.7%、9/9 离座零释放；
根因 = frame0 奇偶偏置 + 绝对 f1 阈值 + 慢漂移。v1.2.1 = 奇偶分链 + 10 s 标定 +
泄漏归一 F1 + Bin1 微动判空 + 快照重建。

## 9. 工程实现

- **契约与自检**：`contract.py` 校验 raw/meta/algorithm/result；detect.py 写盘后
  自动 selfcheck，FAIL 非零退出。
- **CI**：GitHub Actions（ubuntu/windows）跑根 `selftest.py`、C 的
  `tools/selftest_v121.py`（奇偶投影一致性 + 合成生命周期）、DEMO 校验。
- **回归集**：12 组 T01 + 484 + 1,031；`tools/eval_v121.py` 生成 v1.2 vs v1.2.1
  对照表（CSV+MD），`tools/diag_release.py` 打印判空前后 floor/m/f1 轨迹。
- **版本管理**：v1.2 配置/输出冻结；v1.2.1 独立分支 `feat/c-v1.2.1`/PR #9；
  v1.2.1 输出在 `outputs/v1.2.1/<组>/`；算法参数与 notes 写进 algorithm.json。
- **可复现**：`examples/real/`（v1.2 单链）、`examples/real_v121/`（奇偶分链）、
  `examples/live_v121/`（484 抓包）全部入库，命令见 README。

## 10. 已知限制

1. 完全静止 ≥12 s 可能被判空（静坐保持 97–99%）——均值/方差层最小间隔仅 1.2–2.5×。
2. 人未走出雷达波束时不判空（判空延迟 = 离开波束时间 + 5 s）。
3. 20 cm 安装时桌面/雷达整体振动与「座位上有人」不可分（1,031 帧现场疑似），
   需共模抑制或受控复测。
4. 邻座 0 误报依赖入场门槛 4.0（邻座峰值 3.81）；门槛再降会重新引入。
5. 位置/强度未多场景标定（R5），换桌/换人需重标空座。
6. 姿态在当前数据不可分（11/12 拒识），只交付拒识管线。

## 11. 下一步

- **共模抑制**：微动量改在 `|X|/|X0|` 上算，整体振动被 bin0 归一抵消
  （需 B 的逐帧解码数组验证）。
- **空间一致性**：bin1 与 bin3 同时有微动才认「坐在座位」，拒单 bin 瞬态。
- **多安装位置/强度标定**（R5）+ 20 cm/60 cm 两份安装档案。
- **多座位**：先相邻两座的遮挡/串扰与目标归属，再扩六人桌；接口按
  architecture.md 的 node_id/table_id/seat_id 约定升级。
- **A 侧**：倒计时期间的二次确认策略（当前 2 s 连续即取消）可在业务层再评估。
