# M1 v1.2 在 round-2 三组数据上的缺陷分析报告

> 作者：C（算法回放）
> 日期：2026-11-18
> 对象：`T01_P04_retest` / `T01_neighbor_R01` / `T01_aisle_R01`（2026-11-12 采集，config `M1_dev112p_v0.2.json`，sha `b1013256059cc169…` 三组一致）
> 结论先行：**三组 presence 全部被钉死为 1，是 v1.2 的启动脆弱性与绝对阈值标定不迁移共同作用的结构性缺陷，不是数据问题，也不是配置错误。** P01 验证通过带有三重幸存者偏差。修复需算法版本迭代（v1.2.1），属团队决策；本任务配置冻结，官方三件套按原样交付。

|---|---|---|---|
| P04_retest（504 帧，97.3s） | 空座 0–20.3s → 坐 20.3–57.4s → **走远** 57.4–70.7s → 坐 70.7–86.5s → **走远** 86.5s–末尾 | frame 7（t=1.3545s）起 presence=1，**全程 497/504 帧=1，零释放** | 开场空座段全误报；两次走远（49+35 帧）全误报 |
| neighbor_R01（323 帧，62.3s） | **目标座全程空**（邻座 20.28s 坐下、47.8s 离开） | frame 6（t=1.1610s）起 317/323 帧=1 | 全程误报 |
| aisle_R01（313 帧，60.4s） | **目标座全程空**（4 次经过：16.8/23.1/32.9/41.8s） | frame 6（t=1.1610s）起 307/313 帧=1 | 全程误报 |

三组 quality 全部 `ok`；单边沿 0→1 后无任何回落；背景快照均在 **K_eff=1**（种子帧本身）即冻结。

## 2. 根因：三因素叠加

### 因素 A：设备热状态跨度——P01 标定在冷机态

同一会话（2026-11-12）内按时间排列的录制（chip1/rx0 链路，全帧均值）：

| 顺序 | 录制 | 采集时间 | \|b0\|（泄漏） | 空座 \|b1\|（目标座反射体，f12–99） |
|---|---|---|---|---|
| 1 | **P01_formal** | 19:41:47 | **10289** | **3538** |
| 2 | P02_formal | 19:56:02 | 16633 | 8663 |
| 3 | P03_formal | 20:15:26 | 16387 | 8389 |
| 4 | P04_formal | 20:21:57 | 16443 | 8440 |
| 5 | neighbor_R01 | 20:35:07 | 17240 | 8121 |
| 6 | aisle_R01 | 20:46:00 | 17864 | 7277 |
| 7 | P02_retest | 21:46:47 | 16935 | 6990 |
| 8 | P04_retest | 21:58:20 | 21570 | 10245 |
| — | pilot_01 / short_01 / short_02 | （时间未记录） | 18020 / 17699 / 19768 | ~6000–9200（含人段） |

P01 是**开机后 14 分钟内的第一组录制**，泄漏 bin（b0，与场景无关、纯设备链路）只有其余组的 0.49–0.61 倍；目标座反射体（b1）只有其余组的 **0.34–0.51 倍**。f1 的绝对 dB 映射 `f1_db_map [30,43.5]` → 残差幅度阈值 **[31.6, 224] counts，是在 P01 的 3538 基数上开环标定的**（相当于基数的 0.9%–6.3%）。同样的相对变化发生在 7000–10300 基数上，绝对残差放大 2–2.9 倍。

### 因素 B：录制内慢漂移（相对速率各组相当）

空座前缀（f12–99，避开启动段）线性拟合的 |b1| 漂移率：

| 录制 | 漂移率（%/min） | 绝对速率（counts/s，基数≈空座均值） |
|---|---|---|
| P01_formal | −4.5 | ≈ −2.7 |
| P02_formal | −4.0 | ≈ −5.8 |
| P03_formal | −1.9 | ≈ −2.7 |
| P04_formal | −4.4 | ≈ −6.2 |
| neighbor | −3.6 | ≈ −4.9 |
| aisle | −3.7 | ≈ −4.5 |
| P02_retest | −6.2 | ≈ −7.2 |
| P04_retest | −4.1 | ≈ −7.0 |

关键事实：**P01 的相对漂移率与其他组并无差别**（−4.5%/min vs −1.9~−6.2）。它"稳定"只是因为基数低（3538），同样速率下绝对残差只有别人的 0.34–0.51 倍。且漂移呈两级形态：**快初始衰减**（P04_retest 开场 ~11 counts/帧，前 30 帧）+ **慢线性趋势**（~0.7 counts/帧）。60–97 秒的录制内，累计漂移 150–250 counts，**直接打穿 224 的 f1 饱和值**。

### 因素 C：frame-0 种子奇偶计数偏置（+139）

设备 `tx_polling=1` 使奇/偶 chirp 的目标座幅度相差 ~11×（奇 ≈16200、偶 ≈1450 counts）。所有 round-2 录制的 frame 0 都是部分帧（缺 chirp 0–10，53 有效 = **27 奇 + 26 偶**），与完整帧（32/32）的奇偶配比不同，简单均值给种子带来 **+139 counts** 偏置。P01 的 frame 0 恰好缺失 14 个 chirp（0–13，7 奇 + 7 偶），得到 **25/25 精确配比、零偏置——纯属录制时序的幸运**。

### 机制串接：presence 为何钉死

1. frame 0 残差恒 0（bg 预初始化 X[0]）→ 种子吸收 K_eff=1；
2. frame 1 起残差 = 偏置(+139) + 快初始衰减(前 30 帧 ~100+) → f1 饱和 → score≈0.82 > t_on=0.45；
3. confirm=6 满足（frame 6/7）→ **presence=1 冻结一切**；
4. 冻结后 |X−bg| 只增不减（漂移持续）→ f1n 恒 1.0 → score 底数 0.82+，**永不触及 t_off=0.30** → 零释放。

## 3. 关键证据

### 3.1 隔离种子缺陷的 what-if（trim12，诊断性回放，非交付）

裁掉前 12 帧（剔除奇偶偏置种子与最陡初始衰减段）、frame_id 重排 0..n−1 后用 v1.2 原样回放：

| 录制 | 结果 | 说明 |
|---|---|---|
| P04_retest | 仍在 t=10.642s（K_eff=27 后）确认占用，比真实首次坐稳（20.33s）**早 9.7s**；之后 f1n 钉 1.0，**两次走远（9.3s / 9.0s）零释放** | 纯漂移驱动确认 |
| neighbor | t=20.511s 翻 1（与邻座坐下 20.28s 巧合），但 **f1n 在人坐下前（t=16.8s）已 0.41** 且此后单调涨；邻座离开后仍 1 直至结束 | 翻 1 时刻是漂移日程表排的，不是检出人 |
| aisle | t=24.188s 翻 1（近第 2 次经过 23.13s），f1n 自 t=16.8s 起无人时段持续上涨 | 同上 |

**结论：修掉种子问题救不了 v1.2——绝对阈值 × 漂移这一层独立致命。**

### 3.2 邻座/过道事件在目标座 bins 上不可见（正确输出 = 全程 0）

对邻座/过道组做线性去趋势后按事件窗口统计 |b1| 偏移：

- neighbor：邻座坐 +23 → 邻座活动 +81 → **邻座离开后 +158**（偏移随时间单调增长——这是漂移曲率残差的 signature，真实人体事件应为瞬态扰动而非单调增长）；
- aisle：四次经过 Δb1 = +26/+60/+108/+151，**随时间而非随事件增长**；经过窗与空闲窗原始电平无差异（7283→7158 连续单调下降）；Δb2/Δb3 全为噪声级（−7~+12）。

即：这两组的**正确答案就是全程 presence=0**，任何对漂移鲁棒的设计都能拿满分；v1.2 的误报 100% 是漂移伪迹。

### 3.3 P04 的人体签名在方差，不在均值

对 P04_retest 以空座段（前缀+两次走远）拟合线性趋势后对比：

| 窗口 | \|b1\| 均值偏移 | \|b1\| 帧间 std |
|---|---|---|
| 空座前缀 12–18s | — | 12（0.1%） |
| 坐姿 I 24–55s（活动） | −0.56% | **98（1.0%）** |
| 走远 I 61–68s | −0.40% | 8（0.1%） |
| 坐姿 II 74–84s（安静后靠） | −0.26% | **21（0.2%）** |
| 走远 II 89–95s | +0.30% | 9（0.1%） |

- 静坐者的**均值**信号（−0.26%~−0.56%）与漂移残差噪声（±0.3~0.4%）同量级，均值层不可分（走远 I 自身也偏 −0.40%）；
- 但**方差差 2~8×**（空座 0.1% vs 安静静坐 0.2% vs 活动 1.0%）；
- 官方 scores 印证：f1 饱和时占/空 score 差 0.91–0.94 vs 0.84–0.85——是 f3（呼吸带）/f4（跳变）在看人，但它们合计只有 0.2 权重（f1 独占 0.80）。

## 4. P01 验证为何通过：三重幸存者偏差

1. **冷机弱反射体**：基数 3538（全场最低），同样相对漂移的绝对残差只有 0.34–0.51 倍；
2. **frame-0 奇偶恰好 25/25**：种子零偏置；
3. **失败路径从未被触发**：P01 空座段仅 19.7s（漂移累计 ~50 counts，f1n≈0.1）就入座，录制结束时仍占用——「空座漂移→饱和→应释放」这条路径在 P01 上结构性不存在。

P01 的 G1 20/20 验证是真实的，但它的**覆盖面**（单录制、冷机态、单反射体强度、无离座事件）不足以暴露上述任何一层。

## 5. v1.2.1 修复方向（供团队决策，非单选项）

| 方向 | 内容 | 动机 | 局限 |
|---|---|---|---|
| R1 adapter 奇偶平衡 | `chirp_mean` 改为奇/偶分别求均值再平均（或种子帧要求奇偶配比一致） | 消除 frame-0 +139 偏置；属转换层 bug 修复 | **单独不够**（trim12 已证）；对 P01 影响：仅 frame 839（11/12），1dfft 种子不变，重验证成本低 |
| R2 f1 尺度归一 | 残差功率 / 背景功率（CFAR 式相对量）替代绝对 dB map | 消除基数×热状态敏感；邻座/过道组直接全程 0 | **静坐者均值信号 < 漂移噪声（3.3 节）**，归一化 f1 单独检不出安静的人 |
| R3 方差/动态提权 | f1 改方差比（空座 std vs 近期 std），或重标定权重让 f3/f4 能独立过 t_on | 人体签名在方差（2~8×），f3/f4 已实际看到人 | 需重标定+多状态验证集（本轮 8 组即现成验证集） |
| R4 慢速重跟踪背景 | 占用门控的极慢 EMA | 跟踪漂移，释放后残差回落 | τ>30s 时滞后残差仍 ~110 counts（3.7/s×30s），单独不够；τ 小会吸收静坐者 |
| R5 多强度重标定 | 在 6–10k 基数（pilot/round-2 水平）上重标 f1_db_map，并把反射体强度档案纳入 meta | 让阈值落在实际工作点 | 治标：热状态跨度 2.1× 仍会出界，需与 R2 组合 |

**C 的建议组合**：R1（必做，转换层修复）+ R2+R3（核心，让特征对强度/漂移鲁棒且能检出静坐者）+ R5 验证纪律（多座位多强度验证集纳入 G 门）。R2 与 R3 需联合设计——3.3 节证明任何单一手段都不足。
