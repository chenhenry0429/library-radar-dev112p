## 帧级契约（提案正文）

**会话开始握手**（一次）：B 向 C 提供会话 meta，最低字段：

- `data_level`（v0.1 仅 `"1dfft"`；2dfft/B0 与 dsraw 暂留离线）
- `raw_shape`（如 `[2, 2, 64, 8, 2]`）、`raw_dtype`（`int16`）、`axis_order`
- `radar_config.nominal_frame_period_s`（=0.1935；5.168 Hz 是取整标签，不能反推 1/5.168）
- `installation`（区域解析用；与归档 meta 相同结构）

**每帧（DevFrame）**：

| 字段 | 形状/类型 | 说明 |
| --- | --- | --- |
| `raw_frame` | int16 `(chip, rx, chirp, range_fft_bin, iq)` | 单帧切片，轴序同归档 `axis_order` |
| `valid_chirps` | bool `(chip, rx, chirp)` | 单帧有效 chirp 掩码 |
| `frame_id` | int | 0 起严格连续（0,1,2,…） |
| `timestamp` | float 秒 | 名义时间 = frame_id × 0.1935，严格递增 |

**C 侧责任**：chip/rx 选路（默认 chip1/rx0，与交付归档一致）与 chirp 合并投影、区域解析、识别、九字段输出与转发。选路是算法决策，留在 C 侧可随数据演进，不牵动 B。

## 关键决策（请 B 确认）

1. **投影在 C 不在 B**：B 不做复均值，交原始立方+掩码。投影函数与离线转换字节等价（已验证），保证离线/在线可互为回归基准。
2. **丢帧/坏帧的显式表达**：B 在无有效数据的帧号上，仍发送 `raw_frame`（内容可为零）+ **全零 `valid_chirps`** 的帧，保持 frame_id 连续。C 对此输出 `invalid_frame` 行（presence=-1，target_count=-1，不填无人/有人），**不推进识别状态机**（NaN 剖面会毒化相位链），并记录 warning。离线适配器对零有效 chirp 是整卷拒收语义，在线降级为帧级拒收，不需要整卷重采。
3. **frame_id 跳号 = 协议错乱，C 直接报错**：与 A 契约一致（帧号归零→重启会话）。若 B 不发零掩码帧而是静默跳帧，C 无法区分采集丢帧与会话错乱，因此零掩码帧是必需的显式信号。
4. **时间基**：在线会话用名义时间（0.1935 步进）。C 的 F3 呼吸带频率映射依赖帧周期，由握手 meta 提供；回放回归用 `median(diff(ts))` 与离线一致。秒表-雷达时钟偏移问题（D 评价用）不受影响，仍按 B 在办事项。
5. **会话边界**：新录制/新采集会话 = 新 `SeatDetector` + A 侧重启会话。C 不跨会话携带状态。
