## 操作入口

打开 offline_viewer/index.html 后刷新。新增三个验收按钮；异常历史支持跳转，事件表支持筛选。v0.2 原有输出仍可直接导入。
验收场景输出：output/acceptance/采集编号/运行编号/。重新执行 prepare_acceptance.py 会生成新的运行目录，不覆盖既有输出。

显示层只读既有时间线。缺口期间显示最后记录值并标记暂停；初始未知、待确认、复核或缺口均不计入可用空位。无姿态能力时显示未启用，而不是要求用户反复标定。
