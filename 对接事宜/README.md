# 对接事宜

用于记录 A（应用）、B（采集）、C（算法）、D（实验与评价）之间的接口交接、问题处理和联调验收。

## 每次数据更新都同步对接记录

新增录制、补交或更正原始归档、更新标注或补齐回放结果时，在 GitHub `main` 的本目录新增记录，或在对应录制的已有记录中追加本次更新。同步更新本页索引和状态。

每次记录写清以下内容。

1. **这次更新了什么**。记录日期、录制编号、数据分支或提交、可访问的文件链接和验证结果。
2. **发现了什么问题**。写明现场现象、复现条件和证据帧号或时间。尚无异常、原因未确认或范围未覆盖时，注明实际状态。
3. **交给谁做什么**。写明负责成员、具体动作、预计交付物和验收标准，使接手人能直接开始。
4. **下一次复验看什么**。保留本轮结果和待确认事项。组员回传修改版本或验证结果后，在同一条记录追加进展。
